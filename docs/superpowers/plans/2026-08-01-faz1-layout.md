### Task 1: Safe-area — sabit `50` yerine gerçek insets (B5) + üstü açıkta kalan ekranlar (B4)

En görünür kalite sıçraması. `insets.top` cihaza göre 20 (eski) / 47 (notch) / 59-62 (Dynamic Island); sabit `50` Dynamic Island'da içeriği saate sokuyor, eski cihazlarda fazla boşluk bırakıyor.

**Files (B5 — sabit `50` → insets):**
- `app/(tabs)/_lib/styles.ts:16` (ana sayfa header)
- `app/(tabs)/_lib/searchStyles.ts:13` (arama header)
- `app/(tabs)/_lib/profileStyles.ts:16` (profil header)
- `app/product/[id]/_components/ProductTopBar.tsx:68` (absolute üst çubuk)
- `app/messages/[threadId]/_lib/styles.ts:14`
- `src/components/listing/_lib/styles.ts:30` (ilan oluştur/düzenle)
- `app/collections/[id]/_lib/collectionStyles.ts:29` (`top: 50`)

**Files (B4 — üst boşluğu hiç olmayan ekranlar):**
- `app/collections/[id]/edit.tsx:52` — `<Stack.Screen options={{ title: … }} />` var ama `headerShown: true` **yok**; ebeveyn (`app/collections/_layout.tsx:5`) header'ı kapattığı için başlık hiç çizilmiyor. Doğru örnek: `app/collections/[id]/add-items/index.tsx:18`.
- `app/collections/[id]/index.tsx` + `_lib/collectionStyles.ts:23-26` — kapak görseli y=0'dan başlıyor.
- `app/banned.tsx:28`, `app/business-pending.tsx:25` — `headerShown: false` + insets yok.

**Yaklaşım:**
`StyleSheet` içindeki sabit `50`'ler **statik** — `useSafeAreaInsets()` bir hook, stylesheet'te çağrılamaz. Bu yüzden her kullanım yerinde stildeki `paddingTop`/`top` kaldırılıp bileşende çalışma anında verilir:

```tsx
const insets = useSafeAreaInsets();
// ...
<View style={[styles.header, { paddingTop: Math.max(insets.top, theme.spacing[3]) }]}>
```

`Math.max(..., spacing[3])` tabanı: insets 0 dönen ortamlarda (bazı Android, test) header yapışık kalmasın.

`collections/[id]` kapak görseli gibi "header görselin üstünde yüzsün" isteyen yerde `top: insets.top` ile absolute konum ver — kapak görselini aşağı itme.

`banned.tsx` / `business-pending.tsx` için en ucuzu `@/ui` `ScreenHeader` eklemek ya da `SafeAreaView` ile sarmak; bu ekranlar basit, hangisi daha az kod ise onu seç.

- [ ] **Step 1: Testi yaz**

`src/ui/__tests__/safeAreaUsage.test.ts` — regresyon kilidi. `src/config/__tests__/releaseWorkflow.test.ts` bu repoda dosya-içeriği okuyan test deseninin örneği; ona bak.

```ts
import * as fs from 'fs';
import * as path from 'path';

const ROOT = path.resolve(__dirname, '../../..');
const read = (rel: string) => fs.readFileSync(path.join(ROOT, rel), 'utf8');

/** Safe-area'yı elle sabitleyen dosyalar — hepsi insets'e taşındı. */
const MIGRATED = [
  'app/(tabs)/_lib/styles.ts',
  'app/(tabs)/_lib/searchStyles.ts',
  'app/(tabs)/_lib/profileStyles.ts',
  'app/product/[id]/_components/ProductTopBar.tsx',
  'app/messages/[threadId]/_lib/styles.ts',
  'src/components/listing/_lib/styles.ts',
  'app/collections/[id]/_lib/collectionStyles.ts',
];

describe('safe-area disiplini', () => {
  it.each(MIGRATED)('%s içinde sabit 50pt üst boşluk kalmadı', (rel) => {
    const src = read(rel);
    expect(src).not.toMatch(/paddingTop:\s*50\b/);
    expect(src).not.toMatch(/\btop:\s*50\b/);
  });
});
```

- [ ] **Step 2: Testin kırmızı olduğunu gör**

Run: `npx jest src/ui/__tests__/safeAreaUsage.test.ts --ci --silent --forceExit`
Expected: FAIL — 7 dosyanın hepsi hâlâ `50` içeriyor.

- [ ] **Step 3: B5'i uygula (7 dosya)**

Her dosyada: stildeki sabit `paddingTop: 50` / `top: 50` kaldır, kullanan bileşende `useSafeAreaInsets()` ile çalışma anında ver. Bileşen zaten `useSafeAreaInsets` kullanıyorsa yeniden çağırma.

- [ ] **Step 4: B4'ü uygula**

`collections/[id]/edit.tsx:52` → `options={{ title: 'Koleksiyonu Düzenle', headerShown: true }}`.
`collections/[id]/index.tsx`, `banned.tsx`, `business-pending.tsx` → üst boşluk ver (yukarıdaki yaklaşım).

- [ ] **Step 5: Testler yeşil**

Run: `npx jest --ci --silent --forceExit`
Expected: tam suite yeşil (600 + yeni testler).

- [ ] **Step 6: Doğrula + commit**

```bash
npx tsc --noEmit && npx eslint app/ src/
git commit -m "fix(layout): use real safe-area insets instead of a hardcoded 50pt

A fixed 50pt top padding pushed header content under the clock on Dynamic
Island devices and left too much space on older ones. Replace it with
useSafeAreaInsets() in the seven places that bypassed the shared
ScreenHeader, and give the four screens that had no top spacing at all a
proper inset. A regression test locks the constant out."
```

### Task 2: `AdBanner` yer ayırsın (B1)

Ana sayfanın **en tepesinde** duruyor (`app/(tabs)/index.tsx:88`), reklam query'si çözülene kadar yok, çözülünce her şeyi ~110-130pt aşağı itiyor. Kullanıcı tam o an ekranın üstüne bakıyor — en kötü konum.

**Files:**
- Modify: `src/components/ads/AdBanner.tsx:34,67`
- Test: `src/components/ads/__tests__/adBannerReserve.test.tsx` (Create)

**Mevcut davranış:** `AdBanner.tsx:67` → `if (ads.length === 0) return null;`
**İstenen:** query **yüklenirken** de yer kaplasın; yüklenme bitti ve reklam yoksa `null`.

`useAds(position)` hook'unun `isPending`/`isLoading` döndürüp döndürmediğini kontrol et; döndürmüyorsa hook'u genişlet (query'nin kendisi zaten TanStack Query).

**İkinci kayma kaynağı:** `AdBanner.tsx:34` — `aspectRatio` sunucudan geliyor, yoksa 4:1 fallback. Gerçek görsel farklı oranlıysa yükleme sonrası **ikinci** bir kayma olur. Rezerve edilen boşluk ile gerçek banner'ın aynı `aspectRatio`'yu kullandığından emin ol.

- [ ] **Step 1: Testi yaz**

```tsx
// yüklenirken yer ayırır
it('reklam query yüklenirken yer kaplar', () => { /* isPending: true → testID görünür */ });
// yükleme bitti, reklam yok → hiç yer kaplamaz
it('yükleme bitip reklam yoksa hiç render etmez', () => { /* isPending: false, ads: [] → null */ });
```
Mock'u `useAds` üzerinden kur. Gerçek assertion'ları hook'un gerçek dönüş şekline göre yaz — önce `src/components/ads/` altını oku.

- [ ] **Step 2: Kırmızı olduğunu gör** — `npx jest src/components/ads/ --ci --silent --forceExit`
- [ ] **Step 3: Uygula** — `isPending` iken `styles.slot` arka planıyla, doğru `aspectRatio`'lu boş bir `View` bas.
- [ ] **Step 4: Yeşil** — aynı komut.
- [ ] **Step 5: Commit**

```bash
git commit -m "fix(home): reserve the ad slot while its query is loading

The banner sits at the very top of the home screen and rendered nothing
until its query resolved, then pushed the whole feed down by ~120pt right
where the user was reading. Reserve the slot at the same aspect ratio
while loading and collapse it only once we know there is no ad."
```
